# Glossary

## ACX

Audio Class Extensions. Microsoft's newer Windows audio driver framework.

## WASAPI

Windows Audio Session API.

## Shared Mode

Windows mixes audio from multiple applications.

## Exclusive Mode

An application takes direct control of the audio endpoint. Prohibited for this project.

## PCM

Pulse-code modulation. Standard uncompressed digital audio.

## Digital Silence

PCM samples with zero value.

## HDMI Audio Carrier

The active stream of HDMI audio packets and timing information.

## S/PDIF

Sony/Philips Digital Interface. Often used over optical TOSLINK.

## Endpoint

A Windows playback or recording device.
