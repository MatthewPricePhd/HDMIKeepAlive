# ADR-0005-winui3-primary-ui: Use WinUI 3 for UI

## Status

Accepted

## Context

HDMIKeepAlive should be safe, transparent, and maintainable.

## Decision

Use WinUI 3 for UI.

## Consequences

WinUI 3 is modern and appropriate for Windows 11. If packaging becomes a blocker, WPF may be reconsidered through a future ADR.
