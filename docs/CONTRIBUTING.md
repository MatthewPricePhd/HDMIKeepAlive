# Contributing

## Branches

Use feature branches:

```text
feature/audio-engine
feature/ui
feature/settings
fix/reconnect-bug
docs/update-prd
```

## Pull Requests

PRs should include:

- Summary
- Motivation
- Files changed
- Test evidence
- Screenshots if UI changed
- Documentation updates if needed

## Code Review Criteria

- Builds successfully
- Tests pass
- No architectural shortcuts
- No prohibited security behaviors
- Shared Mode only
- No admin requirement

## Issues

Use issue templates for:

- Bug report
- Feature request
- Hardware compatibility report
