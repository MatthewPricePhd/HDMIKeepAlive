# Release Plan

## Versioning

Use Semantic Versioning.

```text
MAJOR.MINOR.PATCH
```

## Release Artifacts

- Framework-dependent zip
- Self-contained win-x64 zip
- Checksums
- Release notes

## Pre-Release Checklist

- Build passes.
- Tests pass.
- Manual delay-prevention test passes.
- No admin required.
- No network access.
- README updated.
- CHANGELOG updated.
- Known issues documented.

## Release Notes Format

```markdown
# HDMIKeepAlive vX.Y.Z

## Added
## Changed
## Fixed
## Known Issues
```
